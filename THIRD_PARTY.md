# Software and scientific credits

LIHPS Sprint Mechanics preview 0.2 uses MediaPipe Pose Landmarker Full (tasks-vision 0.10.32; model full/float16/1), and Mediabunny 1.65.2. These unmodified vendor files are bundled so video processing can remain on the device. Original videos are never uploaded by this application.

- MediaPipe: https://github.com/google-ai-edge/mediapipe (Apache 2.0); licence in vendor/MEDIAPIPE-LICENSE.txt; upstream README in vendor/MEDIAPIPE-README.txt. Model: https://storage.googleapis.com/mediapipe-models/pose_landmarker/pose_landmarker_full/float16/1/pose_landmarker_full.task.
- Mediabunny: https://mediabunny.dev/ ; see vendor/MEDIABUNNY-LICENSE.txt (Mozilla Public License 2.0). Corresponding source for the unmodified bundled version: https://github.com/Vanilagy/mediabunny/tree/v1.65.2 (npm version 1.65.2).
- S-MAS criteria: Bramah C, Tawiah-Dodoo J, Rhodes S, Elliott JD, Dos'Santos T. The Sprint Mechanics Assessment Score: A Qualitative Screening Tool for the In-field Assessment of Sprint Running Mechanics. American Journal of Sports Medicine. 2024;52(6):1608-1616. https://doi.org/10.1177/03635465241235525. The authors' supplementary score sheet and article use CC BY-NC 4.0: https://creativecommons.org/licenses/by-nc/4.0/. Interface descriptions are paraphrased and shortened. No author endorsement is implied. No article photographs are redistributed.
- Prospective evidence: Bramah C, Rhodes S, Clarke-Cornwell A, Dos'Santos T. https://doi.org/10.1136/bjsports-2024-108600 (online 2025).

The event detector, quality flags, user interface and their implementation are new and have not been clinically validated. Original S-MAS research does not validate this software's automatic suggestions.
